**Flex Forest Cruiser**
The project is an app for recording forestry data and transferring it to the wider FRASS system.

**Installation**
The app can be installed via the FRASS website in both Android and IOS. You must enable loading of outside apps.

**Prerequisites**
Nothing

**Functionality**
Upload/Download Cruise Data from FRASS
Gather Tree Data
Determine Habitat Type
